# 找幫助 — 台灣公益團體媒合平台

免費、匿名、不註冊的緊急救助資源搜尋平台。

## 特色
- 825 個台灣緊急救助公益團體
- 10 大緊急服務類別（經濟扶助、心理健康、家暴保護、醫療、身障、兒少、長照、住宅、法律、災害）
- 28 個精選團體提供詳細服務說明、申請方式、分會查詢
- 完全在瀏覽器端搜尋，不收集個資

## 資料來源
- 司法院法人登記公開資料
- 政府開放資料平台 data.gov.tw
- igiving.org.tw 公益資訊整合平台

## 發起
由 [心轉基金會](https://shinnjeng.org) 公益專案發起，不收取任何費用。

## 免責聲明
本平台僅提供資訊參考，不代表對任何團體之背書或推薦。請透過官方聯絡方式直接聯繫確認最新服務內容。
